# Pixel Playground V31 QA

Mobile-only Falling Blocks refinement.

- Falling Blocks score is positioned top-right inside the gameplay frame.
- Lines and level are positioned top-left inside the gameplay frame.
- Mobile controls are directly below the gameplay area.
- Mobile controls are arranged LEFT/RIGHT on row 1 and ROTATE/SOFT DROP on row 2.
- Mobile hard-drop button is removed; keyboard Space remains supported.
- Falling Blocks mobile READY/status text is hidden to preserve vertical space.
- Desktop Falling Blocks layout and mechanics are unchanged.
- Existing V30 baseline retained.
